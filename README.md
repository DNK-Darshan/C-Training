## DataTypes in C
- Datatype tells the compiler 
    - What kind of data variable store
    - How much memory required
    - What operations can perform
    - Range of values

- There are mainly four categories: 
1. Basic Datatypes
    - int
    - char
    - float
    - double

2. Drived Datatypes
    - Array
    - Function
    - Pointer

3. User Defined Datatypes
    - struct
    - union
    - enum
    - typedef
    
4. Void Datatype
